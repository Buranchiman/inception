## Description

The inception project is a project in the 42 curriculum which aims to teach how to use dockers and proper containerisation. This is done through creating a docker for each services of our webpage : nginx, wordpress and mariadb.

## Project description

In this project we are using Dockers to isolate each service and properly control how they interact with eachother. We are using nginx as the only entry point connected to the host. The other services wordpress and mariadb are reachable only from inside the docker network.
